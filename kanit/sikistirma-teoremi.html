Sıkıştırma Teoremi

İki fonksiyon arasına sıkışan bir fonksiyon onların ortak limitine mecburdur — analizin en çok kullanılan tek aracı.

Bu kanıt kaynak listede yok; kendi eklediklerimden. Ama listedeki \(\lim_{x\to 0} x\sin(1/x)\) ve \(\lim_{x\to 0}\frac{\sin x}{x}\) sorularının ikisi de bu teoremle çözüldüğü için burada durması doğru.

Teorem Sıkıştırma (Squeeze) Teoremi

\(g, f, h : D \to \mathbb{R}\) ve \(c \in \overline{D}\) olsun. Bir \(\alpha > 0\) için, \(0 < |x - c| < \alpha\) olan her \(x \in D\)'de

\[g(x) \ \le\ f(x) \ \le\ h(x)\]

sağlansın. Ayrıca

\[\lim_{x\to c} g(x) = \lim_{x\to c} h(x) = L\]

olsun. O hâlde \(\lim_{x\to c} f(x)\) vardır ve \(L\)'ye eşittir.

Kanıt#

Kanıt

\(\varepsilon > 0\) verilsin. Üç yarıçap seçelim:

  1. \(\lim g = L\) olduğundan bir \(\delta_1 > 0\) vardır ki \(0 < |x-c| < \delta_1\) iken \(|g(x) - L| < \varepsilon\); özel olarak
    \[L - \varepsilon < g(x).\]
  2. \(\lim h = L\) olduğundan bir \(\delta_2 > 0\) vardır ki \(0 < |x-c| < \delta_2\) iken \(|h(x) - L| < \varepsilon\); özel olarak
    \[h(x) < L + \varepsilon.\]
  3. Sıkıştırma eşitsizliğinin geçerli olduğu \(\alpha\).

\(\delta = \min(\alpha, \delta_1, \delta_2) > 0\) alalım. \(0 < |x - c| < \delta\) olan her \(x \in D\) için üç bilgiyi zincirleyelim:

\[L - \varepsilon \;<\; g(x) \;\le\; f(x) \;\le\; h(x) \;<\; L + \varepsilon .\]

Uçları okursak \(L - \varepsilon < f(x) < L + \varepsilon\), yani

\[|f(x) - L| < \varepsilon .\]

\(\varepsilon\) keyfî olduğundan \(\lim_{x\to c} f(x) = L\).

□

Not Dikkat edilecek nokta

Teorem \(f\)'nin limitinin var olduğunu da söylüyor; bu bir bonus değil, ifadenin en değerli kısmı. Genelde \(f\) o kadar düzensizdir ki limitinin varlığını doğrudan göstermek imkânsıza yakındır — \(x\sin(1/x)\) tam olarak böyle bir örnek.

Sıfıra sıkıştırma#

Uygulamada en sık kullanılan hâli, mutlak değerli biçimidir.

Sonuç

\(|f(x)| \le g(x)\) ve \(\lim_{x\to c} g(x) = 0\) ise \(\lim_{x\to c} f(x) = 0\).

Kanıt

\(|f(x)| \le g(x)\) eşitsizliği \(-g(x) \le f(x) \le g(x)\) demektir. Ayrıca \(\lim (-g) = -\lim g = 0\) olduğundan alt ve üst fonksiyonların ortak limiti \(0\)'dır. Sıkıştırma teoremi doğrudan sonucu verir.

□

Not Örnek

\(f(x) = x\sin(1/x)\) için \(|f(x)| \le |x|\) ve \(\lim_{x\to 0}|x| = 0\) olduğundan \(\lim_{x\to 0} x\sin(1/x) = 0\). Ayrıntısı şurada.

Lean 4 formalizasyonu#

Mathlib'de sıkıştırma teoremi süzgeç düzeyinde, "sonunda" (∀ᶠ) niceleyicisiyle ifade edilmiştir; bu, "bir \(\alpha\) komşuluğunda" demenin topolojik karşılığı.

import Mathlib

open Filter Topology

variable {f g h : ℝ → ℝ} {c L : ℝ}

/-- Sıkıştırma teoremi. -/
theorem sikistirma
    (hg : Tendsto g (𝓝[≠] c) (𝓝 L))
    (hh : Tendsto h (𝓝[≠] c) (𝓝 L))
    (h₁ : ∀ᶠ x in 𝓝[≠] c, g x ≤ f x)
    (h₂ : ∀ᶠ x in 𝓝[≠] c, f x ≤ h x) :
    Tendsto f (𝓝[≠] c) (𝓝 L) :=
  tendsto_of_tendsto_of_tendsto_of_le_of_le' hg hh h₁ h₂

/-- Sıfıra sıkıştırma: `|f| ≤ g` ve `g → 0` ise `f → 0`. -/
theorem sifira_sikistirma
    (hg : Tendsto g (𝓝[≠] c) (𝓝 0))
    (hle : ∀ᶠ x in 𝓝[≠] c, |f x| ≤ g x) :
    Tendsto f (𝓝[≠] c) (𝓝 0) := by
  have halt : ∀ᶠ x in 𝓝[≠] c, -g x ≤ f x := by
    filter_upwards [hle] with x hx
    have := abs_le.mp hx
    linarith [this.1]
  have hust : ∀ᶠ x in 𝓝[≠] c, f x ≤ g x := by
    filter_upwards [hle] with x hx
    exact (abs_le.mp hx).2
  have hneg : Tendsto (fun x => -g x) (𝓝[≠] c) (𝓝 0) := by
    simpa using hg.neg
  exact tendsto_of_tendsto_of_tendsto_of_le_of_le' hneg hg halt hust

/-- Örnek: `x * sin (1/x) → 0`. -/
example : Tendsto (fun x : ℝ => x * Real.sin (1 / x)) (𝓝[≠] 0) (𝓝 0) := by
  apply sifira_sikistirma (g := fun x => |x|)
  · simpa using (continuous_abs.tendsto (0 : ℝ)).comp tendsto_nhdsWithin_of_tendsto_nhds
  · filter_upwards with x
    rw [abs_mul]
    exact mul_le_of_le_one_right (abs_nonneg _) (Real.abs_sin_le_one _)

Not

Mathlib'de teoremin adı tendsto_of_tendsto_of_tendsto_of_le_of_le' — sondaki kesme işareti, eşitsizliklerin her yerde değil "sonunda" istendiği sürümü gösteriyor. Kesme işaretsiz sürüm ise g ≤ f ve f ≤ h'yi her noktada ister.
